HOW TO PUBLISH THIS VERSION (v1.0.0)
====================================

Nothing has been pushed or deployed from this machine. The work is committed
locally. Push it yourself when you're happy with it.

The repo already points at GitHub:
    origin  https://github.com/kkjjkamal123/kkjj.me.git

------------------------------------------------------------
STEP 1 - Check it locally
------------------------------------------------------------
    npm ci
    npm run check      # lint + tests + production build
    npm run preview    # open http://localhost:5173 and look around

------------------------------------------------------------
STEP 2 - Review what's new
------------------------------------------------------------
    git log --oneline origin/main..main
    cat CHANGELOG.md

------------------------------------------------------------
STEP 3 - Push
------------------------------------------------------------
Use credentials for the kkjjkamal123 account. A GitHub SSH key belongs to
exactly one account, so on a machine whose key belongs to someone else,
use HTTPS with a personal access token:

    git push origin main
    # HTTPS username: kkjjkamal123   password: <personal access token>

------------------------------------------------------------
STEP 4 - It deploys itself
------------------------------------------------------------
The push starts .github/workflows/deploy.yml, which lints, tests, builds
and publishes to GitHub Pages at https://kkjj.me/. Follow it under the
repo's Actions tab. If Pages isn't enabled yet:
Repo -> Settings -> Pages -> Build and deployment -> Source: "GitHub Actions"

Keep VITE_BASE: / in the workflow (custom domain).

------------------------------------------------------------
ALTERNATIVE - Vercel
------------------------------------------------------------
Import the repo at https://vercel.com/new. It picks up vercel.json (build
command, output folder, security and cache headers). See DEPLOY.md.

------------------------------------------------------------
